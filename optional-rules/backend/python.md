# Python 可选规则

## 适用范围

- 仅在项目使用 Python 时启用；先确认解释器版本、依赖锁定及同步或异步运行模式。
- 不默认 Django、FastAPI 或任务框架；类型语法和并发能力与项目版本匹配。

## 约束

- 接收外部数据时，执行运行时校验；类型注解不能替代输入验证。
- 定义模块边界时，为关键输入、输出及可空值提供清晰类型，限制 Any 的传播范围。
- 转换动态数据为领域对象时，在边界集中校验，避免后续代码依赖隐式字典形状。
- 捕获异常时，优先捕获可恢复的具体类型；需要统一边界时保留原因并明确处理策略。
- 转换异常或返回错误时，保留原因链，对外隐藏内部路径、凭据与堆栈。
- 遇到任务取消时，完成必要清理后按异步运行时契约传播，不当作普通业务失败吞掉。
- 使用文件、连接或锁时，采用上下文管理或等价的可靠释放路径。
- 使用 async 函数时，检查调用链中的阻塞 I/O 与 CPU 密集工作，按运行模型隔离执行。
- 创建后台任务时，明确所有者、并发上限、异常收集、取消及关闭等待。
- 多协程或多线程共享状态时，明确同步策略；不要依赖解释器锁保证业务复合操作原子性。
- 定义函数或数据模型默认值时，避免无意共享可变对象；使用独立构造或默认工厂。
- 模块导入时，避免隐式联网、启动线程或改写全局配置；启动副作用由显式入口负责。
- 调用远程服务时，配置超时；重试需有上限并确认操作幂等性。
- 编写日志时，记录可定位的上下文，并过滤用户敏感数据与凭据。

## 验证

- 修改类型边界时，验证非法、缺失、额外字段及空值的运行时行为。
- 修改异常处理时，验证原因链、错误映射与资源释放。
- 修改异步逻辑时，验证超时、取消、任务失败及服务退出。
- 修改共享状态时，验证并发交错与不同实例的默认值隔离。
- 使用项目已有格式、静态检查、类型检查和相关测试入口，注明未配置的检查。
- 依赖真实外部服务的验证仅在明确的隔离测试环境进行，记录替代验证的限制。
