# MySQL 可选规则

## 适用范围

- 仅在项目使用 MySQL 时启用；先确认版本、存储引擎、SQL 模式、字符集及客户端。
- MariaDB 不自动等同于 MySQL；DDL、锁与查询能力须按实际目标确认。

## 约束

- 处理外部查询条件时，使用参数绑定；动态标识符和排序字段使用允许列表。
- 设计表结构时，明确主键、唯一性、空值与关联约束，避免只靠应用约定保证完整性。
- 存储金额或精确数量时，使用匹配精度的定点类型；时间字段说明时区与转换策略。
- 多步写入要求原子性时，使用明确事务边界，并确认引擎支持所需语义。
- 修改并发读写时，明确隔离级别、锁定范围及丢失更新防护。
- 事务持锁期间，避免无界计算或外部等待；需要跨服务协调时设计补偿或可靠事件。
- 发生死锁或瞬态冲突时，仅在确认幂等与预算后有限重试整个事务。
- 新增或调整索引时，以实际过滤、连接、排序和数据分布验证收益，计入写放大成本。
- 使用组合索引时，核对列顺序、范围条件与排序需求，不以索引存在推断已命中。
- 分页处理大数据集时，评估稳定排序与游标方式，避免深分页持续扫描大量丢弃行。
- 变更表结构时，评估元数据锁、表重建、复制延迟及目标版本的在线 DDL 能力。
- 迁移需要回填时，分批执行并提供进度、断点与限速；结构调整和大回填分阶段交付。
- 删除或重命名字段时，先兼容新旧应用读写，再收缩旧结构；不可逆步骤说明恢复方案。
- 配置连接池时，设置容量、获取超时和查询超时，结合数据库连接预算。

## 验证

- 修改查询时，在隔离测试数据上检查执行计划与代表性数据规模。
- 修改事务时，验证回滚、唯一冲突、死锁重试及并发写入结果。
- 修改迁移时，在临时数据库演练升级、兼容窗口和回退或恢复步骤。
- 涉及生产规模时，记录锁等待、执行耗时、连接量与复制影响的评估依据。
- 修改字段类型、字符集或排序规则时，验证边界值、中文与大小写语义。
- 验证使用项目明确配置的测试环境，不提供或执行默认连接真实服务的示例命令。
