# Elasticsearch 可选规则

## 适用范围

- 仅在项目使用 Elasticsearch 时启用；ES 在此指 Elasticsearch。
- 先确认集群与客户端版本、部署模式及兼容范围；不套用其他搜索产品的接口行为。

## 约束

- 建模索引时，明确字段类型、分析器及精确匹配与全文检索边界。
- 接收结构多变的数据时，约束动态映射与字段数量，避免不受控字段膨胀。
- 处理外部搜索条件时，限制可查询字段、分页规模、聚合规模及昂贵查询能力。
- 多租户检索时，在服务端落实可访问数据范围，不能仅依赖前端过滤。
- 调整映射或分析器时，确认能否原地修改；不兼容变更通过新索引重建。
- 建立新索引时，使用可追踪版本与模板配置，明确应用读取和写入的 alias。
- 重建索引时，说明数据源、回填进度、增量追赶以及删除数据的同步策略。
- 切换 alias 前，核对读写目标与写入归属；使用目标版本支持的原子切换方式。
- 回退 alias 时，先确认旧索引是否仍具备最新写入，不能仅把名称切回视为恢复。
- 写入后立即搜索时，明确近实时可见性；refresh 控制搜索可见性，不等同于持久化或副本保障。
- 业务要求读后可见时，选择目标版本支持的等待可见策略，避免逐条强制 refresh。
- 批量写入时，逐项检查失败结果并限流重试，不能仅依据整体请求成功判断全部成功。
- 并发更新或事件乱序时，使用业务版本或适用并发控制，防止旧数据覆盖新数据。
- 设计分片、保留期和大查询时，以容量评估及观测数据决定，避免无依据地增加分片。

## 验证

- 修改映射或分析器时，用代表性中文、空值、数组与边界输入验证索引和查询结果。
- 修改同步流程时，验证重复事件、乱序、删除、批次部分失败及恢复续传。
- 修改重建流程时，在隔离索引演练回填、增量追赶、alias 切换及回退条件。
- 修改一致性逻辑时，分别验证写入确认、按 ID 读取和搜索可见性的约定。
- 修改查询时，检查代表性规模下的延迟、超时、分页及聚合资源开销。
- 所有验证使用临时集群或隔离测试索引，清理动作必须限定测试资源范围。
