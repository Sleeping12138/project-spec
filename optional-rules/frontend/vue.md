# Vue 可选规则

## 适用范围

- 仅在项目使用 Vue 时启用；先从依赖与构建配置确认版本、组件风格及路由方案。
- 不预设 Nuxt、Pinia、Composition API 或特定版本；版本相关行为以项目锁定版本为准。

## 约束

- 组件接收外部数据时，声明输入、事件及可空语义；不要隐式改写父组件拥有的数据。
- 存在跨组件状态时，先明确所有者与更新入口，再决定提升状态或引入共享存储。
- 使用响应式对象时，区分代理、引用与普通快照；解构、替换及传参后确认响应性仍符合预期。
- 使用计算属性时，保持计算过程无外部副作用；仅为派生值建立计算属性。
- 需要监听外部变化时，明确监听源、触发时机和清理方式，避免监听与状态更新形成循环。
- 请求依赖可变化输入时，取消旧请求或校验请求标识，阻止旧结果覆盖新状态。
- 创建定时器、订阅、事件监听或手动 watcher 时，明确生命周期所有者并在结束时释放。
- 组件可能停用后复用时，分别处理停用与销毁，避免重复订阅或隐藏页面继续轮询。
- 列表允许插入、删除或重排时，使用稳定业务标识作为 key。
- 表单双向绑定时，明确可写状态与校验边界；派生只读值不作为写入目标。
- 渲染来自外部的 HTML 或 URL 时，使用适当的清理与协议校验。
- 存在服务端渲染时，隔离浏览器 API，并避免不同请求共享用户状态。
- 优化大列表或深层响应式时，先测量瓶颈，再选择拆分、虚拟化或浅层响应式方案。
- 采用组合逻辑或共享存储时，只暴露调用方需要的状态及操作，并记录副作用与清理职责。

## 验证

- 修改响应式逻辑时，验证输入变化、对象替换和解构后的界面更新。
- 修改异步加载时，验证快速切换输入、乱序返回、失败及卸载场景。
- 修改生命周期逻辑时，验证重复挂载、卸载及启用的缓存组件生命周期。
- 修改列表或表单时，验证重排后的输入归属、提交与校验反馈。
- 项目已有检查入口时，运行相应 lint、构建及类型检查；仅对配置支持的检查作通过声明。
- 运行组件或交互验证时，覆盖本次受影响行为，并记录不能验证的环境限制。
