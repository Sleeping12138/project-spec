# 中间件通用规则

## 适用范围

数据库、缓存、搜索与消息系统交互；具体组件按已启用模块读取。

## 约束

- 连接、凭据、超时和资源池按环境配置，使用最小必要权限，禁止将真实凭据写入示例。
- 先确认当前组件版本、客户端版本和部署方式；版本相关行为查对应官方资料。
- 明确业务事实源与派生数据：缓存和搜索副本的一致性、刷新和恢复方式需要可解释。
- 数据库、消息和远程系统之间的事务不视为天然原子；说明失败窗口、重试、幂等和补偿。
- 连接失败、超时、限流或组件不可用时，按需求选择失败返回、降级或恢复，不能静默吞错。
- 自动重试有边界，维护可观测性，防止重试风暴和无上限积压。
- 迁移、重建、删除、清空等有数据影响的操作提供影响范围和恢复依据，执行遵守授权范围。
- 验证使用隔离实例、索引、主题、Key 前缀或测试数据；共享环境避免与真实业务相互干扰。

## 检查方法

- 检查数据所有权、连接生命周期、超时和重试配置。
- 按改动验证不可用、重复、乱序、并发或恢复场景中的相关项。
- 交付说明环境、版本依据、已验证场景及仍需目标环境确认的内容。
