# 后端规则

## 适用范围

接口、服务、领域逻辑、批处理和异步任务；语言约束按已启用模块读取。

## 约束

- 接口边界校验输入、认证和资源级授权；内部可信调用也要维持明确的契约。
- 请求和响应复用现有字段、状态码、错误格式与分页约定，不强制迁移为新包装格式。
- 数据访问使用参数化查询或安全的结构化 API；动态字段和排序项通过允许列表约束。
- 业务事务边界明确；本地事务与跨系统副作用之间的失败处理有明确设计。
- 对可能重试的写入、回调和消息消费按业务语义设计幂等，不以单次本地成功代表全链路成功。
- 远程调用具备适当超时和取消；重试限定条件、次数及总预算，避免重试非幂等副作用。
- 鉴权、限流和防滥用按暴露面配置；涉及 Cookie 会话的跨站请求遵循项目 CSRF 防护机制。
- 并发、锁和共享资源所有权清楚；按语言和框架管理资源生命周期。
- 日志和指标能定位失败但不泄露凭据或敏感业务内容。

## 检查方法

- 验证相关输入错误、越权、失败传播和兼容性场景。
- 对事务、幂等、并发或远程依赖变化运行对应集成/契约测试。
- 查看新增超时、重试和补偿是否会产生重复执行或资源泄漏。
