# 前端规则

## 适用范围

UI、组件、前端状态、路由和网络请求；Vue、React 的附加约束按已启用模块读取。

## 约束

- 组件职责和状态所有者明确；局部状态就近管理，跨组件共享按现有状态机制处理。
- 异步请求区分加载、成功、空数据、失败状态；有竞态风险时防止过期响应覆盖当前结果。
- 表单在客户端提供及时反馈，权限和关键业务校验仍由服务端执行。
- 交互元素保持语义、键盘可用性和必要标签；错误信息可被用户感知。
- 外部文本按文本渲染；必须使用富文本或原始 HTML 时经过可信的净化边界。
- 身份凭据遵循项目认证设计；避免通过日志、URL或不受控持久化暴露敏感数据。
- 使用现有设计系统与布局约定，变更覆盖受影响的屏幕尺寸和交互状态。
- 性能优化以实际瓶颈或已知规模约束为依据，避免无证据引入缓存与复杂状态机制。

## 检查方法

- 运行相关静态检查、组件或行为测试。
- 涉及渲染或交互时验证受影响页面、错误/空态及必要尺寸；无法运行浏览器时明确记录未验证内容。
- 检查控制台异常、重复请求、资源清理和接口契约变化。
